Collected 16 Nov 2026. This folder holds every reference for the web app redesign. The code lives in `../web/`.

| Folder | What's in it |
|---|---|
| `brand/` | Brand sheet (source of truth for colours and fonts), cat reference + SVG cats, cat prompts, illustration style |
| `figma/` | Screenshots from the Sieve 2.0 Figma file: pitch deck page (34:127), full website (24:128) |
| `app-screens/` | Current app screens (dark mode): overview, find, library, screening, reader, map, prisma |
| `de-docs/` | Design Entrepreneurship material: concept PDF, journey map, market research, pitch story + script |

| `positivus/` | Positivus landing page notes (Figma Community file; the MCP can't read Community files) |
| `previews/` | Redesign previews for approval, one screen at a time |

## Brand (do not change)
Sky `#A9D6FE` · Orange `#F58B23` · Coral `#FAA09B` · Ink `#302C28` · Mist `#EDECED` · Paper `#FFFFFF`.
Instrument Serif headlines, Public Sans body. Text is only ink or white. Orange is never used for text.
Tagline: "Research you can Trust."

## What we take from each reference
- **Positivus**: thick ink outlines, hard offset shadow under cards (`0 5px 0 ink`), big rounded cards (radius 24–45), section headings sitting on a solid colour chip, numbered rows you can open and close, plain grid.
- **Unitap**: alternating step blocks joined by hand-drawn arrows, a 2×2 feature grid with one illustration each, big hero type split over lines. Its dark purple/green web3 colours do NOT carry over.
- **Sieve website/deck (Figma)**: one flat colour per block (sky / coral / ink), line-art glasses cat holding up frames, big serif statements, short copy.
